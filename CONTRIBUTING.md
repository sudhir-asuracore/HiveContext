# Contributing to HiveContext

We welcome contributions from the community!

## Project Structure

- [HiveContext](https://github.com/sudhir-asuracore/HiveContext): Landing page, documentation hub, and GitHub Pages interactive showcase.
- [HiveContext-Dashboard](https://github.com/sudhir-asuracore/HiveContext-Dashboard): Next.js control panel and human review interface.
- [HiveContext-MCP](https://github.com/sudhir-asuracore/HiveContext-MCP): FastMCP server and AWS SAM serverless backend.

## Local Development (Landing Page)

To run and preview the landing page locally:
```bash
python3 -m http.server 8080
```
Open [http://localhost:8080](http://localhost:8080) in your browser.

## Submitting Pull Requests

1. Fork the respective repository and create a descriptive branch.
2. Ensure changes follow code styling and dark-theme aesthetic conventions.
3. Submit a pull request with a summary of the improvements.
