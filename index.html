05 / AGENT INTEGRATION

Connect Any MCP-Compatible Client

Add the HiveContext server configuration to your AI coding assistant configuration file.

Antigravity / Claude Desktop Configuration (~/.mcp.json) 
{
  "mcpServers": {
    "hivecontext": {
      "serverUrl": "https://<your-lambda-url>.lambda-url.<region>.on.aws/sse",
      "headers": {
        "Authorization": "Bearer <your-mcp-secret-token>",
        "X-HiveContext-Tenant": "default"
      }
    }
  }
}
